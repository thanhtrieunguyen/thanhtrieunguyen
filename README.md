## Featured project

### [Aviation Weather AI](https://github.com/thanhtrieunguyen/aviation-weather-ai)

Weather hazard forecasting and flight risk assessment system designed for airport operations across Vietnam.

- Core stack: Python, Node.js, Vue, React Native
- Role: Individual developer
- Architecture: Ingests meteorological METAR observations, trains risk classification models (Random Forest, XGBoost, LightGBM), and serves automated alerts through an API service to dashboard and mobile clients.
- Documentation: [Repository](https://github.com/thanhtrieunguyen/aviation-weather-ai) | [Architecture reference](https://deepwiki.com/thanhtrieunguyen/aviation-weather-ai) | [Portfolio case study](https://trieuthanh.id.vn/)
